처음 설치했다면,
이 순서로 시작하세요.

앱 화면과 사용 안내는 한국어로 제공합니다.

  1. 압축을 풀고 앱을 실행하세요

    설치형 ZIP은 압축을 푼 뒤 설치 프로그램을 실행합니다. 포터블 ZIP은 압축을 푼 폴더에서 앱을 실행하면 됩니다.

  2. 설정에서 다운로드 도구를 준비하세요

    설정 → 도구에서 yt-dlp와 필요한 FFmpeg를 설치하거나, PC에 이미 설치한 도구를 선택하세요. 필요한 도구는 앱에서 안내합니다.

  3. 영상 주소를 붙여 넣고 저장하세요

    다운로드 화면에 주소를 넣고 영상 정보를 확인하세요. 품질과 저장 폴더를 확인한 다음 전체 영상이나 필요한 구간을 내려받습니다.

시작 전에 궁금한 점

yt-dlp GUI는 어떤 프로그램인가요?

yt-dlp는 명령어로 영상을 내려받는 도구입니다. GUI는 버튼과 입력창으로 조작하는 화면을 뜻합니다. dlpad에서는 yt-dlp 명령어를 직접 입력하지 않고 한국어 화면에서 다운로드를 설정하고 진행 상황을 확인할 수 있습니다.

다른 언어로도 사용할 수 있나요?

현재 앱 화면과 사용 안내는 한국어로 제공합니다. 앱에서 언어를 전환하는 기능은 아직 지원하지 않습니다.

다운로드 도구도 따로 설치해야 하나요?

yt-dlp, FFmpeg, Deno 같은 외부 도구는 앱의 설정 → 도구에서 설치하고 버전을 관리할 수 있습니다. 이미 설치한 도구도 선택할 수 있습니다. 각 도구의 배포와 라이선스 조건은 서로 다릅니다.

앱이 자동으로 업데이트되나요?

v0.1.2부터 설정 → 앱 업데이트에서 조회 채널을 미리보기 버전으로 선택해 새 버전을 확인하고, 내려받은 뒤 재시작할 수 있습니다. v0.1.0은 v0.1.4를 한 번 수동 설치하세요. 업데이트 메타데이터는 서명을 검증하지만 Windows 코드 서명은 제공하지 않습니다. 다운로드 도구의 버전 관리는 앱 업데이트와 별개입니다.

시작 메뉴와 Windows 앱 목록에 등록되나요?

v0.1.4 설치형은 현재 사용자용으로 등록하며 포터블은 자동 등록하지 않습니다. 기존 v0.1.2는 새 설치기에서 기존 위치를 확인하고 Windows 등록을 누르세요. 앱 업데이트만으로는 등록되지 않습니다. Windows 목록의 버전은 처음 설치한 버전 기준이라 앱 화면의 버전과 다를 수 있습니다.

앱을 제거하면 영상도 지워지나요?

Windows 설정 → 앱 → 설치된 앱 또는 제어판의 프로그램 제거에서 dlpad를 선택하세요. 영상·설정·다운로드 도구는 보존합니다. 설치가 여러 개면 이름의 짧은 식별자로 구분합니다. 임시 제거 프로그램은 이번 버전에서 자동 정리하지 않습니다.

macOS와 Linux에서도 쓸 수 있나요?

지금은 Windows를 우선 개발하고 검증합니다. 다른 운영체제는 후속 지원 대상이며, 현재 다운로드로 제공하지 않습니다.

계정이나 클라우드가 필요한가요?

dlpad 계정은 필요하지 않습니다. 영상은 선택한 로컬 폴더에 저장합니다. 원본 사이트에서 인증을 요구하는 영상은 해당 사이트의 접근 조건을 따릅니다.
