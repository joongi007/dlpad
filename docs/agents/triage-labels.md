# Triage labels

새 skill용 역할은 로컬 작업 문서의 보조 메타데이터로만 사용한다. 기존 proposed→ready→in-progress→review→done 및 blocked 상태, bug/feature/docs/maintenance 분류와 P0/P1/P2 우선순위를 유지한다.

| 역할 | 의미 |
|---|---|
| needs-triage | 범위·재현·인수 조건 검토 필요 |
| needs-info | 진행에 필요한 증거 부족 |
| ready-for-agent | 파일 소유·의존성·인수 조건이 정리됨 |
| ready-for-human | 별도 사용자 결정/승인 범위에 해당 |
| wontfix | 의도적 제외와 근거 기록 |

외부 서비스의 label 생성이나 tracker 연결은 수행하지 않는다.
