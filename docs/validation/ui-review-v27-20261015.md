## 남은 실제 문제

- Library의 검색 결과 없음 안내가 아래에 가려집니다. 자동 결과 드러내기 후보는 실제 회귀 실패로 아직 미채택이며 History 본문 스크롤도 함께 검토합니다.
- Escape로 고정 도움말을 닫으면 제목 없는 자동 설명이 다시 나타납니다. 위젯별 억제 후보는 별도 검증 중이며 v27에는 포함되지 않습니다.
- 도움말에 포커스가 가면 관련 입력·찾아보기까지 함께 보이도록 그룹 단위 스크롤을 개선 중입니다.
- 800px/200% 도구 화면의 일부 설치·갱신 버튼은 스크롤이 필요합니다. 전체 버튼이 최초 화면에 보인다고 판단하지 않습니다.
- 물리 입력·IME·screen reader·clean OS·현재 빌드 긴 경로·엄격 CPU 성능 인수는 아직 완료하지 않았습니다. 자동 시험은 사용자 데스크톱 대신 private desktop에서 실행했으며 visible fallback은 사용하지 않았습니다.

새 의존성·lock·schema 변경은 없습니다. 서명·외부 게시·공개 릴리스는 수행하지 않았습니다. Git은 exit128로 유효하지 않아 기존 `.git`을 보존했습니다.
