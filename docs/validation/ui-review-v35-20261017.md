# v35: 설치 준비·앱 시작 안내·탐색기 선택

상태: done-scoped / 사용자 검수 대기. 현재 날짜는2026-10-17이며 v34 실험의20261016 namespace는 원 기록으로 보존한다. 최신 후보로 권장하기 전 실제 whole35/패키지/native 결과를 대조한다.

## 사용자 동작

- 설치기의 기존 위치 검사는 정확히 검증한 유일한 journal의 결과를 재사용한다. 수동 재검증을 한 번 더 요구하지 않는다. 초기 기본값에는 입력 debounce를 적용하지 않고 사용자가 편집할 때는 유지한다. 앱 실행 직전의 fresh 검증·취소·기한·Job 수명은 유지한다.
- 시작 중에는 ‘앱 준비 중’과 비활성 이유를 상단에 표시한다. 확인 실패는 오류·재시도로 구분한다. 도구 설정 읽기가 끝날 때까지 안내를 유지한다. 준비 중에는 다운로드용 진행률·취소·일시정지를 표시하지 않는다.
- 로컬 영상 상세의 ‘탐색기에서 파일 선택’은 retained 파일/부모 identity를 검증한 뒤 Windows Shell에 요청한다. 파일 이동/전송은 없다. 자동 시험은 실제 Explorer를 열지 않는다.

현재 SemVer는0.1.0이고 v35는 검수 snapshot 번호다. 설치된 앱을 새 묶음으로 자동 교체하지 않는다. 최신 UI 검수에는 **새 폴더 설치 또는 portable**을 사용한다. 탐색기 버튼은 파일 목록 더블클릭/Enter 또는 ‘선택한 영상 확인’으로 연 로컬 상세에서 사용할 수 있다. 미다운로드 URL은 대상이 아니고 로컬 준비에는 FFprobe가 필요하다.

## 구현·비용

수정 제품 파일은 accessible.rs, catalog.rs, installer_main.rs, installer_catalog.rs, library_open.rs, external_open_broker.rs, media_detail_open.rs다. 새 schema/의존성/Cargo.lock 변경은 없다. 시작 안내의 텍스트 높이 계산은 준비 중에만 수행한다. 외부 앱/탐색기는 앱이 소유한 Job에 직접 spawn하지 않는다. 선택 API 성공은 handoff이고 실제 선택 완료 ack가 아니다. OS 동기 호출은 반환 전 hard-wall 취소를 보장하지 않는다.
