## 원 실패와 남은 작업

Help-v1은 환경 UIA ElementNotAvailable, v2는 Escape settled boolean에서 실패했으나 표본을 assertion 뒤 저장하여 원 boolean을 알 수 없습니다. v3는 실제 전체 조건을 통과했고, 사전 고정 추가2회 중 repeat1은 Escape6통과 뒤 환경 final 조회에서 ElementNotAvailable, repeat2는 전체 조건을 통과했습니다. 이 실패를 성공으로 덮지 않았습니다. 최종 조회·캡처까지 같은 bounded 재조회 loop에 넣은 [v4 자동화 검사](evidence/current-v28-help-private-v4-20261015/root-bindings-review.json)는 actual2ops0/8PNG/41pins·source674 불변·owned app 자연0으로 통과했습니다. [Root 직접5장 검수](evidence/current-v28-help-private-v4-20261015/root-pixel-review.json)에서 경로3행 문맥과 Escape 후 닫힘을 확인했습니다. 고정 설명이 아래 상태·설치 버튼 일부를 가리는 문제는 남아 있으며, v2 원 boolean 미확인과 원 실패 기록을 이 성공으로 덮지 않습니다.

긴 이력 상태 문장의 압축, 도움말의 입력 가림, UIA 간헐 경계, 800/200% 도구 초기 버튼의 추가 scroll, 현재 PE의 strict CPU 비용, 실제 사이트 최종 구간 파일·중단, 현재 긴 경로/로컬CI·물리 IME/reader/DPI·sleep/resume·OneDrive·clean OS가 남았습니다. actual public metadata는 [YouTube 준비 성공·치지직 ToolFailed/보조Exit1](evidence/p0-real-site-metadata-v3-20261015/root-review.json)이며 실제 GUI·다운로드 성공이나 이전 실패 원인을 입증하지 않습니다.
