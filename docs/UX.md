# 사용 흐름과 종료 계약

## 첫 실행

바로 URL 입력 화면을 보여준다. 저장 위치는 Documents/dlpad로 표시하고 변경 가능하다. 필요한 도구를 감지하여 `기존 설치 사용`, `앱에서 설치`, `나중에`를 제시한다. 설치 전 항목별 크기·출처·앱 관리 여부를 보여준다. 도구가 없어도 파일 목록·설정은 사용할 수 있다.

업로드 로그인이나 속도 측정을 초기 필수 단계로 만들지 않는다. 패키지 설치 단계에서 선택할 수 있는 플랫폼은 동일한 도구 선택을 제공하고, portable/macOS drag-install은 첫 실행에서 제공한다.

## 다운로드

URL 붙여넣기 → 제목/영상 길이/가능한 품질 확인 → 기본 품질·저장 폴더 표시 → 다운로드. playlist는 전체를 즉시 시작하지 않고 범위와 개수를 확인한다. 메타데이터 조회는 취소 가능하고 실패 시 입력을 보존한다.

구간은 `전체 / 구간 지정`. `HH:MM:SS[.mmm]` 입력, 8시간 이상 표시, 음수·역전·길이 초과 검사. `빠르게 자르기`에는 키프레임 차이 가능성을, `정확하게 자르기`에는 재인코딩·시간·화질 비용을 설명한다. 소스가 구간 요청을 지원하지 않으면 전체 다운로드 후 자르기 비용을 보여준다.

로그인은 필요한 작업에서만 브라우저 프로필 또는 쿠키 파일을 선택한다. 실패하면 `쿠키를 읽지 못했어요. 브라우저 잠금 또는 암호화 방식 때문일 수 있어요.`처럼 원인과 대안을 보여준다. 업로드 연결과 다운로드 쿠키 인증은 다른 설정이다.

## 창 닫기·종료

아직 사용자가 선택하지 않은 기본 정책은 `작업 중이면 확인`이다. 선택 기억은 설정에서 변경한다.

| 행동 | 동작 |
|---|---|
| X, 활성 작업 없음 | 앱 종료. 숨은 상시 프로세스를 남기지 않음 |
| X, 활성 작업 있음 | `백그라운드 계속 / 중단 후 종료 / 돌아가기`, 선택 기억 가능 |
| 백그라운드 계속 | 현재 Linux 구현: 같은 창을 숨기고 작업 유지, 같은 data 디렉터리로 앱 재실행 시 복귀. 창/renderer 자원 해제와 트레이·메뉴바는 후속 목표 |
| 트레이 없는 Linux 환경 | 백그라운드 복귀 수단 검증 전에는 창 유지/최소화 제안 |
| 메뉴의 앱 종료 | 활성 작업이 있으면 중단 결과 확인, 프로세스 트리 종료 후 앱 종료 |
| 작업 일시 중단 | partial 보존, 소스별 재개 한계 표시 |
| 작업 취소 | 재시도 대기 해제, partial 삭제는 별도 선택 |
| OS 종료·로그아웃 | 제한된 종료 시간 안에 상태 기록, 다음 실행에서 Interrupted 복구 |
| 절전·회선 전환 | 깨어난 후 연결 재검증. 재시도 대기 표시 |

다운로드 중 절전 방지 옵션은 기본 해제 제안. 사용하면 실행 중에만 OS inhibitor를 잡고 종료 시 해제한다. background 중 마지막 작업 완료 후 알림·자동 종료·유지 설정은 후속 제안이다. 현재 구현은 숨김을 유지하며 사용자가 재실행해 결과를 확인한다. 실제 OS 알림 권한이 없으면 작업 이력에 결과를 남긴다.

## 파일 목록과 설정

파일 목록은 열기, 폴더에서 보기, 다시 스캔, 출처 보기(알려진 경우), 목록 숨기기를 제공한다. 파일 삭제는 대상 경로와 개수를 보여주며 OS 휴지통을 우선한다. 실행 중 파일은 삭제할 수 없도록 한다.

설정 구획: 일반(저장 위치/테마/닫기), 다운로드(품질/동시성/속도/재시도), 도구(설치/버전/업데이트/제거), 인증(쿠키), YouTube 업로드, 고급 옵션, 저장 공간·진단.

앱 제거 준비 화면은 `앱 관리 도구`, `설정·이력`, `캐시` 용량을 별도로 표시한다. 다운로드 미디어는 기본 보존한다. macOS 앱을 휴지통에 버리는 등의 OS 동작에서는 제거 질문을 실행할 수 없으므로 앱 내 정리와 OS별 제거 안내를 제공한다.

## 2026-10-01 개발 동작 검증

다운로드 화면의 일시 중단은 소유 프로세스 종료 확인 후 Paused로 기록하고 미완료 파일을 보존한다. 이력에서 같은 작업 ID로 명시적으로 재개한다. 작업 취소는 Cancelled로 기록하고 재개하지 않는다. 두 명령은 첫 종료 요청 뒤 전환하지 않는다. [격리 GUI/실패 검증](validation/pause-validation.md)을 실행했다. Linux 숨김·재실행 복귀는 별도 가상 화면 검증을 따른다. Windows/macOS 복귀와 OS별 logout·sleep 실증은 아직 남는다.

## 목록 검색 후보 — 2026-10-15

파일 목록 상단에서 파일명이나 경로를 입력하고 검색 버튼 또는 Enter로 찾는다. 작업 이력에서는 작업 ID 또는 저장된 영상 URL을 찾는다. 각 화면의 Ctrl+F는 검색창으로 이동하며, 검색 지우기는 전체 목록으로 돌아간다. 현재 화면의 일부 행만 걸러내지 않고 DB의 전체 현재 기록에서 찾는다. 결과가 많으면 다음 페이지를 사용한다.

입력 초안과 실제 표시 중인 검색어를 구분한다. 새 결과가 도착하기 전에는 이전 결과임을 표시하며, 조회 실패 시 기존 목록을 빈 결과로 바꾸지 않고 오류를 보여준다. 검색은 파일 열기·삭제·재개 권한을 만들지 않으므로 해당 동작은 기존 재검증을 유지한다. 작업 이력에 저장하지 않는 제목이나 설정 전체 검색을 지원한다고 안내하지 않는다. 현재 소스 후보이며 v25 배포본에는 없다. [구현·실제 검증 상태](work-items/S03-list-search-ux-20261014.md).

## 2026-10-15 작은 화면의 검색·도움말

파일 검색이 빈 결과이면 안내를 한 번 드러내고, 이력의 명시 검색은 첫 결과/빈 안내를 같은 본문 scroll에서 드러낸다. 입력 focus는 유지하고 늦은 결과/수정 중 draft/실패/Stop은 자동이동하지 않는다. Escape는 정보 설명을 완전히 닫으며 같은 focus만으로 다시 열리지 않는다. 도구 경로는 도움말·입력·찾아보기 focus 시 가능한 전체 문맥을 드러낸다. 현재 통합 소스의 회귀를 검증했으나 사용자에게 제공한 v27 ZIP에는 이 후속 수정이 없으며 새 전체/실제 창/설치 검증을 통과한 후보만 최신으로 안내한다.

## 2026-10-16 로컬 영상 열기와 도구 조회 진행

로컬 영상 상세의 기본 앱 열기는 저장된 원 파일을 OS 연결 앱으로 여는 명시 행동이다. 연결 앱이 없다는 정확한 거절에서만 다른 앱 선택으로 이어지며 일반 오류를 임의 재실행하지 않는다. 다른 앱 선택도 별도 버튼으로 제공한다. 미다운로드 URL은 로컬 영상 열기 대상이 아니다. 외부 앱 실행 요청과 실제 재생 여부를 구분하고, 파일 변경·취소·시간초과·지원불가를 설명한다. Windows 실제 사용자 선택창과 macOS/Linux는 아직 검증하지 않았다.

설정의 도구는 설치된 도구 확인·새 버전 확인·설치·검증·삭제·사용 적용의 진행 문구를 구분한다. 이 문구가 다운로드가 시작됐다는 뜻은 아니다. 조회 중 기존 목록을 유지하고 완료·실패 후 진행 표시를 해제한다. source31 전체 검증 중이며 현재 v30 ZIP에는 이 변경이 아직 없다.

## 시작 준비와 로컬 파일 위치 확인

앱 준비 중에는 상단에 확인 중인 이유를 표시한다. 이전 작업 확인 실패는 확인 중과 구분하고 같은 자리에서 재시도한다. 도구 설정을 읽는 동안에도 준비 안내를 유지하며, 완료하면 사라진다. 안내를 보려고 비활성 버튼을 누르거나 hover할 필요가 없다. 입력 focus를 강제로 이동하지 않는다.

로컬 영상 상세는 **탐색기에서 파일 선택**을 제공한다. 원 파일과 부모를 다시 검증한 뒤 Windows Shell에 그 파일을 선택하도록 요청한다. 파일을 이동·전송하지 않으며 실제 Explorer 선택 완료를 앱이 확인했다고 표현하지 않는다. URL 자체는 이 동작의 대상이 아니다. 다운로드한 파일은 파일 목록에서 더블클릭/Enter 또는 ‘선택한 영상 확인’으로 로컬 상세를 연다. 이 경로는 로컬 영상 준비에 필요한 FFprobe를 사용한다.

설치기는 기존 설치의 최초 정확한 검증 결과를 표시용 실행 준비 상태에 재사용한다. 실행 직전의 fresh 검증은 유지한다. 기존 설치가 확인되면 **앱 실행**을 다음 행동으로 제공하며, 확인 중에는 잠긴 이유를 표시한다. 현재 버전 0.1.0과 v34 검수 번호는 별개다. 버전 비교·안전한 교체 기능 없이 버튼을 ‘업데이트’라고 표시하지 않는다.
