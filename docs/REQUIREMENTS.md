## 경계

앱의 구현 언어는 Rust이지만 외부 yt-dlp 자체는 Rust가 아니다. standalone 배포물에 Python 런타임이 포함될 수 있다. UI에 웹 런타임을 쓰지 않는 것과 외부 다운로드 도구의 내부 기술은 구별한다.

라이브 녹화와 8시간 VOD는 다른 기능이다. P0는 긴 VOD 안정성, P1은 치지직 등 라이브 녹화를 별도 검증한다. DRM 우회, 모든 사이트의 영구 지원, 중단한 라이브의 누락 구간 자동 복원은 보장하지 않는다.

브라우저 캐시는 영상 저장 버퍼로 사용하지 않는다. 로그인 쿠키 사용과 디스크 기반 `.part`/fragment 이어받기를 제공한다. 업로드는 다운로드 가능한 파일마다 자동 승인되는 기능이 아니며, 사용자가 선택한 파일·계정·공개 범위를 따른다.

## 출시를 막는 실패

데이터 손실, 다른 도구 삭제, 비밀 유출, 중복 업로드를 무시한 재시도, 종료 후 제어되지 않는 자식 프로세스, 화면에만 완료로 표시되는 미완성 파일, 소스 길이에 비례하는 메모리 증가.

## 최초 릴리스 플랫폼 범위

사용자 지시에 따라 최초 릴리스 P0는 Windows에서 인수한다. R01–R08/R10/R13의 플랫폼 동작은 Windows 실제 근거로 검증하며 Linux/macOS 인수는 후속이다. 기능·실패복구·진단 요구는 유지한다. [범위 계약](work-items/P0-windows-first-release.md)을 따른다.

## UI/UX 추가 인수 — 2026-10-07

사용자 피드백에 따라 R04/R05/R08의 UI 인수는 URL의 문법과 실제 영상 확인을 구별하고, 영상 내용 미리보기·로컬 영상 드롭·시각 구간 선택과 시간 입력 왕복을 포함한다. GTMUX의 정보 위계와 hover/pressed/selected/focus/disabled/loading/error, 스크롤 경계 및 반응형 구조를 실제 화면/입력으로 검증한다. 단위 테스트 또는 정적 캡처 수만으로 이 인수를 완료하지 않는다. 현재 저해상도 무음 미리보기 후보와 로컬 export 등 남은 범위는 [작업 기록](work-items/S00-media-workspace-interaction.md)에 명시한다.
