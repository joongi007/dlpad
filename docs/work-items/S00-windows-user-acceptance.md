- 선행 작업: 고정 후보의 빌드·자동 회귀·격리 GUI 검증. 최종 manifest picker는 Windows 전체 검증과 private GUI5사례 인수를 완료했다.

## 사용자 결과

사용자가 후보 버전과 미완료 범위를 알고 직접 설치 화면과 앱 사용성을 평가한다. 자동 시험 통과를 사용자 UI/UX 승인으로 표현하지 않는다.

## 계약과 범위

최신 개발 ZIP에는 명세 파일 선택 버튼이 포함되며 나머지 폴더는 명시 입력한다. 최신 소스와 ZIP의 기능 차이를 명시한다. 일반 사용자 인수용 후보에는 실행 방법, 별도 임시 데이터 경로, 알려진 제약을 함께 제공한다. 자동 시험은 private desktop을 유지하며 사용자 화면을 자동으로 띄우지 않는다.

## 인수 조건

사용자가 설치·첫 실행·한글 입력·목록·옵션·취소·숨김/복귀·재시작·진단의 흐름을 직접 평가하고 발견한 문제를 기록한다. 임시 자료를 사용하며 실제 영상·Documents를 필수 시험 조건으로 삼지 않는다. 현재 개발 설치 검증과 향후 정식 설치 프로그램 인수를 구분한다. 사용자 승인은 아직 받지 않았다.

## 검증과 handoff

2026-10-06: 직접 사용 체크리스트를 개발 설치 안내에 추가했다. 코드 변경이나 새로운 빌드 성공을 주장하지 않는다. 새 picker 통합 검증 후 후보를 갱신하고 해당 후보의 정확한 실행 경로와 기능 범위를 제공한다. 실제 사용자 평가·물리 IME·DPI·스크린리더 인수는 미완료다.

### 사용자 후보 준비

현재 whole의 앱 본체 SHA80b657…와 CLI SHA bbcf66…는 직전 검증본과 동일하고 새 설치 화면만 변경됐다. 별도 TEMP 경로 실행 안내를 docs/development/windows-user-preview.md에 추가했다. PowerShell 예시는 사용자 직접 실행용이며 아직 실제 실행 인수는 하지 않았다. 최신 native 선택 시험은 UIA 식별·호출 오류 두 건을 보존하고 재시험 중이다.

### 최종 자동 인수 완료

최종 Windows850/0/13·전체4검사와 명세 선택/취소/종료·재시작 확인취소/제거5사례를 완료했다. [사용자 실행 안내](../development/windows-user-preview.md)에 최신ZIP과 자식 프로세스 TEMP 경로 예시가 있다. 사용자 직접 평가·물리IME/reader 인수는 계속 미완료이며 이 작업은 in-progress를 유지한다.

### 2026-10-07 사용자 UI 평가

사용자는 gtmux 가이드 미준수, 앱 아이콘 부재, 현대적이지 않은 UX를 지적했다. 사용자 UI/UX 인수는 미통과이며 [재작업](S00-windows-user-ui-rework.md)으로 추적한다. 기능 자동 검증 성공을 UI 완성도로 표현하지 않는다.
