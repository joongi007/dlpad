## 사용자 결과

고급 옵션에서 기본 정책과 변경 항목을 빠르게 구분하고 기본값으로 되돌릴 수 있다. 자세한 예시·충돌·버전 정보는 필요할 때 읽는다.

## 계약과 범위

설명 요약과 현재 기본값은 각 입력 근처에 보이고 반복 예시/충돌/영향 정보는 같은 키보드 접근 가능한 상세에 둔다. R07 도움 정보는 삭제하지 않는다. 원 값/검증/plan/ID와 core argv 정책을 보존한다. 모든 기본값 복귀는 사용자의 명시적 버튼 동작으로만 한다. 단위 선택 및 네트워크 관측 연결은 후속 구현으로 진행한다.

## 인수 조건

기본값→유효 사용자 입력→오류→기본값 복귀 후 core advanced 없음과 오류 제거를 실제 Form에서 확인한다. 도움 상세에 예시/충돌/버전이 남아 있다. 작은 화면에서 안내와 입력이 겹치지 않는다.

## 검증과 handoff

현재 고급 옵션에 반복되는 기본값·예시·충돌과 버전 정보가 긴 세로 목록을 만들어 읽기 부담이 큼을 source 및 캡처에서 확인했다. 아직 후속 UI 인수 완료는 아니다.

- root가 입력 요약·기본값을 유지하고 예시/충돌/영향 정보를 단일 상세에 모았으며 명시 기본값 복귀 버튼을 추가했다. 실제 Form 상세 회귀는 펼친 상태의 예시/충돌 보존을 검증하도록 갱신했다. core/schema/argv/의존성 변경 없음. whole56568 실행 중이며 실제 reset 동작·native 시각 인수는 아직 완료가 아니다.

- 첫 whole56568/독립88972 exit0,1205/0/30. 후속으로 실제 입력 placeholder에 각 기본값을 표시하고 기존 Form 회귀에 사용자 Reset Click→원기본 plan/값비움/오류제거를 추가했다. helper·지속 ID·core 옵션 의미를 보존하며 후속 검증한다.
