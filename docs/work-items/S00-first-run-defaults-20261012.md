## 사용자 결과

첫 실행에 저장 폴더가 문서/dlpad로 자동 표시되며 최고 품질·전체 구간·고급 기본 정책으로 사용할 수 있다. 사용자 지정값은 기본값보다 우선한다.

## 계약과 범위

저장값이 없는 경우에만 기본 경로를 resolve한다. 경로 resolve는 복구 worker에서 실행하고 첫 화면 표시만으로 사용자 media 폴더를 만들지 않는다. 유효하지 않은 기존 저장값은 기본값으로 조용히 바꾸지 않고 복구 오류를 표시한다. 사용자 later edit/closewait/env override를 보존한다. 테스트는 주입한 임시 경로만 사용한다.

## 인수 조건

설정 없음→기본값 표시/폴더 미생성, 저장값→복원, 환경값 및 사용자 편집 보존, default resolve 실패→수정 가능한 오류, restart 사용자 설정 보존. 실제 Windows 첫 입력란 및 최고 품질·전체 구간을 확인한다.
